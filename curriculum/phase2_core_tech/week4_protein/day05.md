# Day 5: Phase 2 종합 — 핵심 기술 스택 정리와 조합 전략

> 이전 학습(Phase 2 Week 4 Day 4)에서 단백질 언어 모델(ESM·ProtTrans)이 서열을 "언어"로 학습해 구조·기능·변이 효과를 예측하는 표현 계층임을 다뤘습니다. 오늘은 Phase 2 전체 — 물성 예측(Week 1), 분자 생성(Week 2), ADMET/독성(Week 3), 단백질·구조(Week 4) — 를 하나의 **기술 스택**으로 조립합니다. 개별 기술을 나열하는 대신, 이들이 신약개발 파이프라인에서 어떻게 맞물려 돌아가는지, 그리고 1인 창업자가 어디를 먼저 잡아야 하는지가 오늘의 핵심입니다.

## 개요

Phase 2에서 배운 네 영역은 각각 독립된 도구가 아니라 — 하나의 **폐루프 설계 엔진(closed-loop design engine)** 의 부품입니다. 생성 모델이 후보 분자를 제안하고(Week 2), 물성·ADMET 예측이 그 후보를 걸러내며(Week 1·3), 구조·도킹·단백질 모델이 표적과의 결합을 검증하는(Week 4) 순환이 AI 신약개발의 핵심 루프입니다. 이 루프를 이해하는 것이 중요한 이유는 — 개별 모델의 정확도보다 *어떤 순서로 어떤 필터를 적용하느냐*가 실제 후보의 질을 좌우하기 때문입니다. 오늘은 이 스택의 구조, 데이터 흐름, 그리고 약학 전공자가 어느 지점에서 차별적 판단을 제공하는지를 종합합니다.

## 핵심 개념

### 1) Phase 2의 네 영역 재정리

각 Week가 답한 질문을 한 문장으로 압축하면 스택의 논리가 드러납니다.

| Week | 주제 | 답한 질문 | 대표 기술 |
|------|------|----------|----------|
| **W1** | 물성 예측(QSAR) | "이 분자는 어떤 성질을 갖는가?" | RF/XGBoost, GNN, 분자 Transformer |
| **W2** | 분자 생성 | "원하는 성질의 분자를 어떻게 만드는가?" | VAE/GAN, 강화학습, 확산 모델 |
| **W3** | ADMET/독성 | "이 분자가 약이 될 수 있는가?" | ADMET 예측, hERG/간독성, MPO |
| **W4** | 단백질·구조 | "표적에 실제로 결합하는가?" | AlphaFold, 도킹/DiffDock, ESM |

핵심은 — W2가 **생성(generation)**, W1·W3·W4가 **평가·필터(evaluation)** 를 담당한다는 이분법입니다. 생성은 탐색 공간을 넓히고, 평가는 그 공간을 좁힙니다. 신약개발의 본질이 "10^60 규모의 화학 공간에서 소수의 후보로 수렴"하는 문제임을 상기하면, 이 생성-평가 균형이 곧 파이프라인 설계의 전부입니다.

> **약학적 대응** — 이 구조는 약학의 **hit-to-lead 최적화** 과정과 정확히 대응합니다. 전통적으로 medicinal chemist가 SAR(구조-활성 관계)을 보며 유사체를 합성하고(생성), in vitro 어세이·ADME 패널로 걸러냈습니다(평가). AI 스택은 이 반복을 계산으로 앞당길 뿐 논리 구조는 동일합니다. 약학 전공자는 *어떤 평가 필터가 임상적으로 결정적인지*(예: hERG는 조기 탈락, 용해도는 제형으로 보정 가능)를 알기에 필터의 우선순위와 임계값을 정할 수 있습니다.

### 2) 다중 파라미터 최적화(MPO)라는 통합 원리

Week 3에서 다룬 **다중 파라미터 최적화(Multi-Parameter Optimization, MPO)** 는 Phase 2 전체를 관통하는 통합 개념입니다. 좋은 약물 후보는 활성(W1·W4)이 높으면서 동시에 ADMET(W3)이 양호하고 합성 가능해야 합니다 — 이들은 서로 상충(trade-off)합니다. 지용성을 높여 투과성을 얻으면 용해도·hERG 위험이 오르는 식입니다.

- **단일 목표 최적화의 함정**: 활성만 극대화한 분자는 대개 ADMET이 나쁩니다.
- **MPO 스코어**: 여러 예측값을 가중 결합한 하나의 점수(desirability function)로 후보를 순위화합니다.
- **파레토 최적(Pareto front)**: 어느 한 속성을 희생하지 않고는 개선 불가능한 후보 집합을 남깁니다.

### 3) 표현(representation)의 계층 통일

Phase 2를 관통하는 두 번째 축은 **표현**입니다. 소분자는 SMILES·분자 그래프(W1), 단백질은 서열 임베딩(W4)으로 표현되며 — 생성·예측·도킹 모델이 모두 이 표현 위에서 작동합니다. 소분자의 SMILES와 단백질의 ESM 임베딩은 각 modality의 "공통 언어"이며, 둘을 결합하면 결합 친화도 예측(protein-ligand affinity) 같은 교차 과제로 확장됩니다.

## 작동 원리와 아키텍처

Phase 2 스택을 하나의 폐루프로 조립한 참조 아키텍처 — 1인 창업자가 바이브코딩으로 단계적으로 구축 가능한 구조:

```
[생성 → 평가 → 선별 → 반복]

1. 표적 준비 (W4)
   - 서열 → ESMFold/AlphaFold 구조 + 결합 포켓 검출
   - 핵심 잔기 보존성 → druggable hotspot 태그

2. 후보 생성 (W2)
   - 생성 모델(확산/RL)로 포켓 맞춤 분자 제안
   - 조건: 포켓 형태 + 목표 물성 프로파일

3. 다단계 필터 (W1 + W3)
   - 1차: 물성 예측(pIC50, LogP, 용해도) — 빠른 GNN
   - 2차: ADMET 패널(CYP, hERG, 간독성)
   - 3차: 합성 가능성(SA score)

4. 결합 검증 (W4)
   - 도킹/DiffDock으로 표적-후보 결합 포즈·스코어
   - 상위 후보만 정밀 스코어링

5. MPO 순위화 + 약학적 해석 레이어
   - desirability 가중 결합 → 파레토 프론트
   - 약학 판단: 임계값·탈락 기준·제형 보정 가능성
   → 상위 후보를 다음 생성 라운드로 피드백
```

**스택 조립의 핵심 설계 결정** — 1인 창업자 기준:

| 결정 | 선택지 | 추천 | 이유 |
|------|--------|-----|------|
| 진입 지점 | 생성 먼저 / 평가 먼저 | **평가(필터) 먼저** | 데이터·검증 쉬움, 즉시 가치 |
| 필터 순서 | 무거운 것부터 / 가벼운 것부터 | **가벼운 것부터** | 값싼 예측으로 조기 탈락, 비용 절감 |
| 모델 선택 | 자체 학습 / 오픈 활용 | **오픈(ESM-2, RDKit) 우선** | 백본 무료, 해자는 해석 레이어 |
| 통합 방식 | 엔드투엔드 / 모듈 파이프라인 | **모듈 파이프라인** | 디버깅·교체·검증 용이 |

> **바이브코딩 팁** — 스택 전체를 한 번에 만들려 하지 마십시오. RDKit 물성 계산 → ADMET 예측 API → 도킹 순으로 *하나의 필터씩* 붙여 각 단계를 검증하며 확장하는 것이 현실적입니다. 창업자의 초점은 "각 모델을 어떻게 짜는가"가 아니라 *"어떤 순서의 필터가 우리 표적에서 최선의 후보를 남기는가"* 입니다.

## 신약개발 적용

폐루프 스택을 실제로 운영하는 대표 사례를 통해 Phase 2 기술의 통합 가치를 확인합니다.

| 사례 | 통합한 기술 | 성과 |
|------|-----------|------|
| **Insilico Medicine — INS018_055 (2023~2024)** | 생성(Chemistry42) + 물성·ADMET 필터 + 표적 발굴 | 특발성 폐섬유증(IPF) 후보를 발굴~전임상 약 18개월, Phase 2 진입 |
| **Recursion — 표현형 스크리닝 + 화학** | 대규모 물성·이미지 데이터 + 생성 | 자동화 실험실과 예측 모델 결합, 다수 파이프라인 |
| **Isomorphic Labs (2024~)** | AlphaFold 3 구조 + 결합 예측 | 릴리·노바티스와 파트너십(총 계약가 수십억 달러 규모, 확인 필요) |
| **Iambic Therapeutics** | 구조 기반 생성 + ADMET 공동 최적화 | NeuralPLexer 등 자체 구조·생성 스택 |

**전통적 파이프라인 대비 통합 스택의 이점**:

| 단계 | 전통적 접근 | Phase 2 통합 스택 |
|------|------|------|
| 후보 발굴 | HTS(수백만 화합물 물리 스크리닝) | 생성 모델 + in silico 필터 |
| ADMET 검증 | 후기 단계 실험(비용·시간 큼) | 초기 예측으로 조기 탈락 |
| 표적 결합 | 결정학 + 실험 어세이 | 구조 예측 + 도킹 사전 순위화 |
| 반복 주기 | 합성-시험 수주~수개월 | 계산 루프 수시간~수일 |

> **산업적 통찰** — Phase 2의 진짜 교훈은 개별 모델의 SOTA 여부가 아니라 *조합*입니다. Insilico의 성과도 단일 모델이 아니라 표적 발굴·생성·필터를 잇는 파이프라인 통합에서 나왔습니다. 약학 전공자에게 이 지점이 결정적인데 — 어떤 필터를 어느 순서로, 어떤 임계값으로 적용할지는 순수 ML 지식이 아니라 *임상적으로 무엇이 치명적인가*에 대한 판단이기 때문입니다.

## 창업 관점

Phase 2 스택 전체를 처음부터 만들려는 창업자는 대개 실패합니다. 이유는 명확합니다 — Insilico·Recursion 같은 풀스택 플레이어는 수천억 원의 자본과 자동화 실험실을 갖췄고, 1인 창업자가 그 전체를 재현할 수는 없습니다. 현실적 전략은 스택의 **한 접점(interface)** 을 깊게 잡는 것입니다.

가장 유망한 진입점은 세 가지입니다. 첫째, **필터 계층 특화** — 생성은 남의 모델(또는 오픈 툴)에 맡기고, 특정 표적군의 ADMET·독성·선택성 예측에 약학 지식을 결합한 "정밀 필터 SaaS"를 제공합니다. 활성만 맞히는 도구는 많지만, hERG·간독성을 임상 기준으로 등급화하고 제형 보정 가능성까지 판단하는 도구는 드뭅니다. 둘째, **표적-리간드 접점** — Week 4의 구조·단백질 모델과 Week 1의 물성 모델을 잇는 결합 친화도 예측·포켓 특화 리포트로, 소분자와 바이오로직스 사이의 빈 공간을 노립니다. 셋째, **워크플로 통합** — 흩어진 오픈소스(RDKit, ESM, DiffDock)를 하나의 재현 가능한 파이프라인으로 묶어 중소 바이오·학술 랩에 제공하는 인프라 플레이입니다.

시장 관점에서 이 세 방향의 초기 고객은 풀스택을 구축할 여력이 없는 중소 바이오텍·CRO·학술 랩이며, 이들은 "전체 플랫폼"이 아니라 *자기 파이프라인의 한 구멍*을 메울 도구를 원합니다. 기술적 해자는 오픈 모델 자체가 아니라 — 약학적 해석 레이어, 특정 표적군의 검증 데이터, 그리고 필터 순서·임계값에 담긴 도메인 판단입니다. MVP 구상은 Phase 3(확장 기술·최신 트렌드)로 넘어가기 전, 지금까지의 스택 중 *하나의 접점*을 골라 실제 표적 하나에 대해 end-to-end 데모를 만드는 것입니다.

## 오늘의 과제

1. **Phase 2 스택 한 장 지도 작성 (50분)**: Week 1~4에서 배운 핵심 기술을 "생성 vs 평가" 축과 "소분자 vs 단백질" 축의 2×2 매트릭스로 배치하고, 각 칸에 대표 기술·대표 도구·대표 회사를 채우세요. 완성한 지도에서 — (a) 본인이 가장 자신 있는 칸, (b) 시장에서 가장 붐비는 칸, (c) 상대적으로 비어 보이는 칸을 각각 표시하고 이유를 한 문단으로 정리하세요.

2. **폐루프 파이프라인 설계 문서 (60분)**: 관심 표적 1개(예: KRAS G12C, EGFR 등)를 정하고 — 위 "작동 원리" 아키텍처를 참고해 생성→필터→검증→MPO의 5단계 파이프라인을 본인 표적에 맞게 구체화하세요. 각 단계에서 (a) 사용할 오픈 도구, (b) 적용할 필터와 임계값, (c) 약학 전공자로서 추가할 판단 규칙을 1페이지로 서술하세요. 특히 필터 순서(무엇을 먼저 걸러 비용을 아낄지)를 명시하세요.

3. **통합 스택 스타트업 1사 해부 (50분)**: Insilico Medicine·Iambic·Isomorphic Labs 중 1사를 골라 — (a) Phase 2의 어떤 기술들을 어떻게 통합했는지, (b) 그들의 파이프라인에서 검증된 성과(후보·기간·파트너십)와 아직 미검증인 주장, (c) 1인 창업자가 이들과 정면 경쟁하지 않고 보완·틈새로 진입할 지점을 표로 정리하세요. 결론으로 본인의 진입 가설을 3문장으로 요약하세요.
