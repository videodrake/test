# Day 4: 역합성 분석 — AI가 합성 경로를 설계한다

> 이전 학습(Day 3)에서 합성 가능성(SA) 스코어가 "이 분자를 만들 수 있는가?"를 빠르게 근사한다는 것을 배웠습니다. 특히 3세대 RAScore는 역합성 계획기가 실제로 경로를 찾았는지를 정답 라벨로 삼았습니다. 오늘은 그 라벨을 만들어내는 엔진 자체, 즉 **역합성 분석(retrosynthesis analysis)** 의 내부로 들어갑니다. "만들 수 있는가?"라는 예/아니오 판정을 넘어, "그렇다면 **어떤 반응을 어떤 순서로** 거쳐 만드는가?"라는 경로(route) 자체를 AI가 설계하는 원리를 다룹니다.

## 개요

**역합성 분석**은 목표 분자(target)에서 출발해 결합을 거꾸로 끊어가며(disconnection), 상업적으로 구입 가능한 출발물질(building block)에 도달할 때까지의 합성 경로를 역방향으로 탐색하는 방법입니다. 1960~70년대 E. J. Corey가 체계화한 개념으로, 그는 이 공로로 1990년 노벨 화학상을 받았습니다. 문제의 본질은 **탐색(search)** 입니다 — 하나의 분자를 끊는 방법은 수십~수백 가지이고, 각 조각을 또 끊어야 하므로 경로의 수가 지수적으로 폭발합니다. AI 역합성은 이 거대한 탐색 트리에서 "실현 가능하고 짧고 값싼" 경로를 신경망 정책으로 골라내는 기술입니다. de novo 생성 모델이 아무리 좋은 분자를 그려도, 이 엔진이 경로를 찾지 못하면 그 분자는 종이 위에만 존재합니다.

## 핵심 개념

### 1) 순합성 vs 역합성, 그리고 retron

- **순합성(forward synthesis)**: 반응물 → 생성물. "이 시약들을 섞으면 무엇이 나오는가?"
- **역합성(retrosynthesis)**: 생성물 → 반응물. "이 목표 분자를 만들려면 무엇에서 출발해야 하는가?" 화살표를 이중선(⇒, retrosynthetic arrow)으로 표기합니다.
- **절단(disconnection)**: 목표 분자의 특정 결합을 끊어 더 단순한 전구체(precursor)로 되돌리는 조작.
- **retron**: 특정 반응을 역으로 적용할 수 있게 해주는 목표 분자 내의 부분구조 패턴. 숙련된 약화학자는 분자를 보며 익숙한 retron(예: β-hydroxy ketone → aldol 절단)을 즉시 인식합니다.

> **약학적 대응** — 역합성적 사고는 약학 전공자에게 낯설지 않습니다. **약동학의 역추론**과 구조적으로 같습니다. 관찰된 혈중농도-시간 곡선(결과)에서 흡수·분포·소실 파라미터(원인)를 역산하는 PK 모델링처럼, 역합성은 관찰 가능한 최종 구조(결과)에서 그것을 만든 반응 단계(원인)를 역산합니다. 두 경우 모두 "가능한 원인들의 공간"이 넓고, 그중 데이터·기전에 부합하는 해를 골라야 한다는 점이 동일합니다.

### 2) 두 가지 접근 — 템플릿 기반 vs 템플릿 프리

단일 단계(single-step) 역합성, 즉 "이 분자를 만드는 **한 번의** 반응은 무엇인가"를 예측하는 방식은 크게 둘로 나뉩니다.

- **템플릿 기반(template-based)**: 문헌 반응에서 추출한 **반응 규칙(reaction template)** 을 목표 분자에 매칭합니다. 규칙은 "이런 부분구조는 이런 전구체에서 온다"는 SMARTS 패턴입니다. 해석 가능하고 화학적으로 타당하지만, 학습 데이터에 없는 새로운 반응은 제안하지 못합니다.
- **템플릿 프리(template-free)**: 반응을 **번역(translation)** 문제로 봅니다. 생성물 SMILES를 입력, 반응물 SMILES를 출력으로 하는 시퀀스-투-시퀀스(seq2seq) 트랜스포머를 학습시킵니다. 새로운 절단을 제안할 유연성이 크지만, 문법적으로 틀린 SMILES나 화학적으로 불가능한 반응을 낼 위험이 있습니다.

| 구분 | 템플릿 기반 | 템플릿 프리 |
|------|-------------|-------------|
| 대표 방식 | 규칙 추출 + 신경망 우선순위화 | Molecular Transformer (seq2seq) |
| 해석 가능성 | 높음(규칙이 명시적) | 낮음(블랙박스 생성) |
| 신규 반응 | 어려움(규칙에 종속) | 가능(유연) |
| 실패 양상 | "제안할 규칙 없음" | 비유효 SMILES·불가능 반응 |

### 3) 단일 단계에서 다단계로 — 탐색이 핵심

단일 단계 예측만으로는 부족합니다. 전구체를 또 절단하고, 그 전구체를 다시 절단해 **구입 가능한 물질**에 닿아야 완결됩니다. 이는 트리 탐색(tree search) 문제이며, 바둑·체스와 같은 구조입니다. 그래서 AlphaGo에서 검증된 **몬테카를로 트리 탐색(Monte Carlo Tree Search, MCTS)** 이 표준으로 채택되었습니다.

## 작동 원리와 아키텍처

다단계 역합성 시스템은 세 개의 신경망과 하나의 탐색 알고리즘으로 구성됩니다. Segler 등이 2018년 *Nature* 에 발표한 3N-MCTS가 이 구조의 원형입니다.

```
시스템 구성:
1. 확장 정책(expansion policy) 신경망:
   현재 분자 → 적용할 만한 상위 k개 반응 규칙 제안 (트리 가지 생성)
2. 필터(in-scope filter) 신경망:
   제안된 반응이 실제로 말이 되는가 검증 (비현실적 가지 제거)
3. 롤아웃/가치(rollout·value) 추정:
   이 전구체에서 building block까지 갈 가망이 있는가 평가
4. MCTS 루프:
   선택(select) → 확장(expand) → 평가(evaluate) → 역전파(backpropagate)
   → 모든 잎이 구매 가능 물질이면 경로 완성
```

탐색의 종료 조건(정지 기준)은 명확합니다 — 트리의 모든 잎 노드(leaf)가 **상업 카탈로그에 존재하는 building block**(예: Enamine, Sigma-Aldrich 재고)이면 그 경로는 "풀렸다(solved)"고 판정합니다. Day 3의 RAScore가 예측하던 바로 그 solvability가, 여기서는 탐색을 실제로 돌려 얻는 결과입니다.

| 설계 결정 | 선택지 | 실무적 고려 |
|-----------|--------|-------------|
| 단일 단계 모델 | 템플릿 기반 / 템플릿 프리 | 재현·해석 중시면 템플릿 기반 |
| 탐색 알고리즘 | MCTS / A* / retro* | 경로 품질 vs 속도 |
| 종료 기준(stock) | 어떤 카탈로그를 "구매 가능"으로 볼지 | 조달 현실을 좌우 |
| 경로 랭킹 | 단계 수 / 비용 / 수율 예측 | 고객이 실제로 원하는 축 |

> **바이브코딩 팁** — 이 시스템을 처음부터 짜는 것은 무모합니다. 오픈소스 AiZynthFinder가 위 3N-MCTS 구조를 그대로 구현해 공개돼 있으므로, Claude Code로는 "AiZynthFinder를 백엔드로 호출하고, 반환된 경로 트리를 파싱해 단계 수·building block 가용성·개략 비용으로 재랭킹하라"고 지시하는 것이 실전입니다. 핵심 설정값은 **stock 파일**(어떤 카탈로그를 구매 가능으로 볼지)과 **정책 모델**입니다 — 이 둘만 바꿔도 결과가 크게 달라지므로, 여기가 제품 차별화의 지렛대입니다.

## 신약개발 적용

역합성 AI는 이미 실전 도구 생태계를 이룹니다.

| 도구 / 사례 | 주체 · 연도 | 특징 |
|-------------|-------------|------|
| **3N-MCTS** | Segler et al., *Nature* 2018 | 역합성에 MCTS+신경망을 결합해 화학자 대상 이중맹검에서 문헌 경로와 구분 어려운 수준 달성 |
| **AiZynthFinder** | AstraZeneca, 2020 | 3N-MCTS의 오픈소스 구현. 1인 창업자의 실전 백엔드 |
| **Molecular Transformer / IBM RXN** | Schwaller et al., 2019 | 반응을 번역으로 다룬 템플릿 프리, 웹 서비스로 공개 |
| **ASKCOS** | MIT, 2019~ | 역합성+조건 예측+경로 평가를 통합한 오픈 플랫폼 |
| **Synthia** (구 Chematica) | MilliporeSigma | 전문가 규칙 기반 상용 강자, 실험 검증 사례 다수 |

**구체적 성과** — Segler 등의 2018년 연구에서, AI가 제안한 역합성 경로와 실제 문헌 경로를 화학자들에게 이중맹검으로 제시했을 때 유의미하게 구분하지 못했습니다. Chematica(현 Synthia) 팀은 2018년 알고리즘이 설계한 경로 여러 건을 실험실에서 실제로 합성해 재현성을 입증한 바 있습니다. 이는 역합성 AI가 데모 수준을 넘어 wet lab 검증(Day 4 in Week 4에서 다룰 실험 검증의 상류 단계)으로 이어졌음을 보여줍니다.

> **산업적 통찰** — Day 3에서 make-on-demand(REAL Space)와 de novo 생성을 대비했습니다. 역합성은 이 둘을 잇는 다리입니다. de novo가 그린 신규 골격에 대해 역합성기가 경로를 찾으면, 그 경로의 building block이 REAL 카탈로그에 있는지 확인하는 순간 "새롭지만 만들 수 있는" 분자가 됩니다. 약화학·약학 전공자의 자리는 여기서 결정적입니다 — 알고리즘이 제안한 경로의 시약이 **유전독성 불순물(genotoxic impurity)** 을 남기지 않는지, **잔류 금속 촉매**가 규제 한계를 넘지 않는지, 중간체가 불안정하거나 독성이 크지 않은지를 읽어내는 것은 순수 화학정보학 모델이 놓치는 지점입니다.

## 창업 관점

역합성 AI는 **알고리즘은 오픈소스로 상향평준화됐지만, 그 위의 판단과 통합은 열려 있는** 전형적 시장입니다. AiZynthFinder·ASKCOS가 무료로 강력하기 때문에 "우리가 역합성을 더 잘한다"는 소구는 통하지 않습니다. 고객(중소 바이오·CRO·제약 화학팀)이 실제로 지불하는 지점은 **경로 그 자체가 아니라 경로에 대한 의사결정**입니다.

경쟁 구도는 세 층입니다. 상단에 **Synthia(MilliporeSigma)** 같은 상용 강자, 중간에 **PostEra**·**Chemify**(확인 필요) 등 역합성·합성 자동화 스타트업, 하단에 **AiZynthFinder·ASKCOS·IBM RXN** 오픈소스가 깔려 있습니다.

약사-창업자의 차별화 지점은 세 갈래입니다.

- **경로 랭킹 + 조달 통합**: 역합성기가 뱉는 수십 개 경로를 단계 수·수율 예측·building block 실시간 가격·리드타임으로 재정렬해 "지금 이 순서로 발주하세요"를 제시하는 SaaS. 학술 도구가 무시하는 조달 현실을 메웁니다.
- **규제·안전 해자**: 각 경로의 시약·중간체를 유전독성 불순물·잔류 촉매·용매 등급(ICH Q3 계열) 관점에서 사전 점검해 "규제 리스크가 낮은 경로"에 가점하는 레이어. 순수 화학정보학 팀이 갖기 어려운 약학·규제 지식이 곧 방어벽입니다.
- **생성-역합성 폐루프**: Day 3의 생성 모델과 오늘의 역합성기를 하나의 루프로 묶어, 만들 수 없는 분자는 애초에 생성 단계에서 감점하는 통합 파이프라인. 개별 도구를 붙이는 것을 넘어 워크플로 자체를 판매합니다.

MVP는 명확합니다 — AiZynthFinder를 백엔드로 두고, 입력 분자(또는 후보 리스트)에 대해 **① 상위 경로 3개, ② 각 경로의 building block 가용성·개략 비용, ③ 규제·안전 경보**를 한 장의 리포트로 자동 산출하는 웹앱을 바이브코딩으로 만드는 것입니다. 설득 논리는 "우리가 경로를 찾아준다"가 아니라 **"당신 팀이 어느 경로를 먼저 시도해야 하는지를 알려준다"** 입니다. 다음 Day 5에서 이번 Week의 가상 스크리닝→합성 가능성→역합성을 하나의 "예측에서 실험 검증까지" 흐름으로 종합합니다.

## 오늘의 과제

1. **템플릿 기반 vs 템플릿 프리 논증 (40분)**: 두 접근을 (a) 해석 가능성, (b) 신규 반응 제안 능력, (c) 대표적 실패 양상의 세 축으로 비교하는 표를 만들고, "규제 제출용 문서화가 중요한 제약사 고객에게는 어느 쪽이 유리한가"를 한 문단으로 논증하세요.

2. **MCTS 종료 기준 분석 (50분)**: 역합성 탐색에서 "stock(구매 가능 물질) 파일"을 어떻게 정의하느냐가 결과를 어떻게 바꾸는지 분석하세요 — (a) stock을 대형 상용 카탈로그로 넓히면, (b) 사내 재고로만 좁히면 각각 경로 길이·비용·현실성이 어떻게 달라지는지를 정리하고, 이 설정이 왜 제품 차별화의 지렛대인지 1페이지로 작성하세요.

3. **역합성 SaaS 가설 (50분)**: "역합성 경로를 규제·조달 관점으로 재랭킹하는 SaaS"의 가치 제안을 3문장으로 쓰고 — (a) 핵심 기능 3가지, (b) 초기 고객(중소 바이오 / CRO / 학술 랩 중 택1)과 지불 이유, (c) AiZynthFinder·ASKCOS가 무료인데도 고객이 비용을 내는 이유(= 조달·규제·통합 해자)를 각각 논증하세요.
