# Day 4: 세포/유전자 치료와 AI — CAR-T, 유전자 편집 최적화

> 어제(Day 48)는 mRNA·siRNA·ASO 등 RNA 치료제의 서열 공간을 AI가 어떻게 설계하는지 배웠습니다. 오늘은 한 걸음 더 나아가, 유전정보 자체를 세포 안에서 **영구적으로 바꾸거나 재프로그래밍**하는 세포·유전자 치료(cell & gene therapy)로 이동합니다. RNA 치료제가 "일시적 스위치"라면, 오늘의 주제는 "환자의 세포를 살아있는 약(living drug)으로 만드는" 접근입니다. 설계 대상이 서열에서 **세포·벡터·편집 도구**로 확장되며, AI의 역할과 약학적 판단의 무게도 함께 커집니다.

## 개요

**세포치료(cell therapy)**는 환자 또는 공여자의 세포를 조작해 치료제로 쓰는 방식이고, **유전자 치료(gene therapy)**는 유전자를 세포 안에 전달하거나 교정해 질병의 근본 원인을 바꾸는 방식입니다. 대표적으로 **CAR-T**(키메라 항원 수용체 T세포)는 환자의 T세포에 암세포 인식 수용체를 삽입해 "살아있는 항암제"로 만듭니다. **CRISPR 유전자 편집**은 특정 DNA 위치를 잘라 교정합니다. 2023년 12월 FDA가 승인한 **Casgevy**(exa-cel)는 CRISPR-Cas9로 겸상적혈구병을 치료하는 최초의 유전자 편집 치료제로, 이 분야가 임상적으로 입증되었음을 보여줍니다. 문제는 설계 변수가 폭발적으로 많다는 점입니다 — CAR의 도메인 조합, CRISPR의 가이드 RNA 서열, 전달 벡터의 캡시드까지 모두 최적화 대상입니다. AI는 이 거대한 설계 공간에서 효율·안전성·특이성을 동시에 만족하는 후보를 탐색하는 핵심 도구로 부상했습니다.

## 핵심 개념

### 1) 세 가지 설계 축은 최적화 목표가 다르다

세포·유전자 치료는 하나의 기술이 아니라, 개입 지점이 다른 여러 도구의 묶음입니다. AI가 무엇을 예측·최적화해야 하는지도 축마다 다릅니다.

| 설계 축 | 대표 기술 | AI 설계의 핵심 목표 |
|---------|-----------|---------------------|
| **세포 조작** | CAR-T, TCR-T, NK세포 | 항원 특이성↑, 지속성(persistence)↑, 소진(exhaustion)↓ |
| **유전자 편집** | CRISPR-Cas9, base/prime editing | on-target 효율↑, **off-target**↓ |
| **전달 벡터** | AAV, 렌티바이러스, LNP | 조직 특이적 감염력↑, 면역원성↓, 역가(titer)↑ |

### 2) 약학의 PK/PD가 "세포 동역학"으로 확장된다

전통 약물에서 우리는 혈중 농도-시간 곡선(PK)과 약효(PD)를 다뤘습니다. 그런데 CAR-T는 투여 후 체내에서 **증식(expansion)하고, 수축(contraction)하며, 일부가 기억세포로 지속(persistence)**됩니다. 즉 약물이 스스로 농도를 바꾸는 셈입니다. 약동학의 언어로 보면, 투여량(dose)과 최종 노출(exposure)의 관계가 선형이 아니며, Cmax와 AUC를 세포 증식 곡선으로 재정의해야 합니다. 이 지점이 약학 전공자의 강점입니다 — CAR-T의 확장 피크(보통 투여 후 7~14일)와 지속 기간을 약동학 파라미터로 해석하고, 반응·독성과 연결하는 판단은 순수 ML 엔지니어가 하기 어렵습니다.

### 3) 안전성 프로파일이 완전히 다른 차원이다

CAR-T의 대표 독성인 **사이토카인 방출 증후군(cytokine release syndrome, CRS)**과 **면역효과세포 관련 신경독성(ICANS)**, 그리고 정상 조직을 공격하는 **on-target/off-tumor** 독성은 저분자 약물의 hERG·간독성과는 다른 안전성 체계를 요구합니다. 유전자 편집에서는 의도치 않은 위치를 자르는 **off-target 편집**과 대규모 결실·염색체 재배열이 핵심 위험입니다. AI 예측 모델의 출력이 "임상적으로 허용 가능한가"를 판단하려면 이러한 규제·안전성 맥락의 이해가 필수입니다.

## 작동 원리와 아키텍처

AI가 가장 성숙하게 적용된 영역은 **CRISPR 가이드 RNA(gRNA) 설계**입니다. 두 가지를 동시에 예측해야 합니다: (1) 목표 위치를 얼마나 잘 자르는가(on-target 효율), (2) 다른 곳을 잘못 자를 위험(off-target)은 얼마인가.

```
gRNA 설계 파이프라인 (개념)
1. 입력: 표적 유전자 서열 + PAM(NGG) 위치 스캔 → 후보 gRNA 목록
2. on-target 예측: 서열 → CNN/트랜스포머 → 절단 효율 점수(0~1)
3. off-target 탐색: 유전체 전체에서 유사 서열(미스매치 허용) 검색
4. off-target 위험 점수: CFD 스코어 또는 딥러닝 모델로 각 부위 채점
5. 종합 랭킹: 효율↑ · off-target 위험↓ 를 만족하는 gRNA 상위 N개 출력
```

on-target 효율 예측은 Doench 등이 2016년 제시한 **Rule Set 2(Azimuth)**가 고전적 기준선이며, 이후 **DeepCRISPR**(Chuai 등, 2018), **DeepSpCas9**(Kim 등, 2019), **CRISPRon**(Xiang 등, 2021) 등 딥러닝 모델이 정확도를 높였습니다. off-target 위험은 **CFD(Cutting Frequency Determination) 스코어**가 표준적으로 쓰이며, 딥러닝 기반 모델이 미스매치 패턴의 비선형 효과를 보강합니다. 설계 결정을 표로 정리하면:

| 설계 결정 | 선택지 | 고려 사항 |
|-----------|--------|-----------|
| 편집 도구 | Cas9 / base editor / prime editor | 정밀도 vs 편집 범위 트레이드오프 |
| on-target 모델 | Rule-based / CNN / 트랜스포머 | 데이터량과 서열 문맥 길이 |
| off-target 평가 | CFD / 딥러닝 / 실험(GUIDE-seq) | 계산 예측 후 실험 검증 필수 |
| 전달 방식 | AAV / LNP / 전기천공 | 표적 조직과 면역원성 |

**전달 벡터(AAV) 캡시드 설계**에도 AI가 적용됩니다. 자연 AAV는 특정 조직 지향성(tropism)과 기존 면역(중화항체)의 한계가 있어, 캡시드 단백질 서열을 변형해 새로운 성질을 얻으려 합니다. 캡시드 서열은 수백 개 아미노산으로 이뤄져 조합이 천문학적이므로, 실험 데이터로 학습한 모델이 "감염력이 높고 면역 회피가 되는" 변이체를 예측하는 방식(활성학습·서열-기능 모델)이 쓰입니다.

## 신약개발 적용

구체적 사례로 이 기술의 현재 위치를 봅니다.

- **Casgevy(exa-cel), 2023년 12월 FDA 승인**: CRISPR Therapeutics와 Vertex가 개발한 최초의 CRISPR 유전자 편집 치료제입니다. 환자의 조혈모세포를 체외에서 편집(BCL11A 인핸서를 절단해 태아 헤모글로빈 재활성화)한 뒤 다시 주입하는 *ex vivo* 방식으로, 겸상적혈구병과 수혈의존성 베타지중해빈혈에 승인되었습니다.
- **Intellia NTLA-2001(nex-z)**: 트랜스타이레틴 아밀로이드증을 대상으로, 지질나노입자(LNP)로 CRISPR를 간에 전달해 몸 안에서 직접 편집하는 *in vivo* 방식입니다. 체외 조작 없이 1회 정맥 투여로 표적 단백질을 지속적으로 낮춘다는 점에서 패러다임 전환으로 평가됩니다(임상 진행 중).
- **Dyno Therapeutics**: George Church 연구실에서 출발한 회사로, 머신러닝 기반 AAV 캡시드 설계 플랫폼(CapsidMap)을 앞세워 Novartis·Roche·Sarepta·Astellas 등과 대형 파트너십을 체결했습니다. AI가 벡터 자체를 최적화하는 대표 사례입니다.

기존 방법과 비교하면 개선점이 분명합니다:

| 항목 | 전통적 접근 | AI 접근 |
|------|-------------|---------|
| gRNA 선택 | 소수 후보 실험 시행착오 | 수천 후보를 in silico 사전 랭킹 |
| off-target 평가 | 전량 실험(비용·시간↑) | 예측으로 우선순위화 후 핵심만 검증 |
| AAV 캡시드 | 자연형 스크리닝 | 데이터 학습 기반 신규 변이체 설계 |
| CAR 도메인 | 경험적 조합 | 서열-기능 모델로 후보 축소 |

## 창업 관점

세포·유전자 치료는 2024년 기준 수백억 달러 규모로 성장 중이며, 승인 제품이 늘면서 "설계·최적화 도구" 수요가 커지고 있습니다. Phase 3(트렌드) 단계인 만큼 제품·경쟁 관점을 구체적으로 봅니다.

- **제품 아이디어**: (1) gRNA 설계 SaaS — 표적 유전자를 입력하면 효율·off-target을 함께 예측해 최적 gRNA를 반환하는 API, (2) CAR-T developability 스크리닝 — 항원·도메인 조합의 지속성·독성 위험을 사전 평가, (3) AAV 캡시드 최적화 서비스 — 조직 특이성·면역 회피 변이체 설계.
- **시장·경쟁**: 인프라 계층에 Benchling·Form Bio, 벡터 설계에 Dyno, RNA/올리고 설계에 Deep Genomics 등이 있습니다. 편집 도구 자체(Intellia·CRISPR Tx·Caribou)와 도구를 지원하는 소프트웨어 계층은 구분됩니다. 창업자는 후자, 즉 "설계·안전성 예측 도구" 계층에서 진입 여지가 큽니다.
- **기술적 해자(moat)**: 공개 알고리즘만으로는 차별화가 어렵습니다. 핵심은 **자체 실험 데이터** — 실제 편집 효율·off-target·면역원성을 측정한 독점 데이터셋과, 그 출력을 **임상·규제 맥락으로 번역하는 약학적 판단**입니다. 약사-창업자는 CRS/ICANS 위험, on-target/off-tumor, FDA 세포·유전자 치료 가이드라인을 근거로 "이 예측이 임상에서 무엇을 의미하는가"를 설명할 수 있어, 순수 기술 팀 대비 신뢰와 규제 대응에서 우위를 가집니다.
- **MVP 구상**: 바이브코딩으로 공개 on-target 모델(예: Azimuth)과 off-target CFD 스코어를 조합한 gRNA 랭킹 웹앱을 먼저 만들고, 사용자 실험 결과를 수집해 자체 모델로 고도화하는 데이터 플라이휠을 설계할 수 있습니다.

## 오늘의 과제

1. **(리서치 정리)** Casgevy(exa-cel)의 작용 기전을 1페이지로 정리하세요. BCL11A 인핸서 편집이 왜 태아 헤모글로빈을 재활성화하는지, *ex vivo* 방식의 장단점은 무엇인지 약학적 관점에서 서술합니다.
2. **(비즈니스 분석)** gRNA 설계 도구를 제공하는 소프트웨어/서비스 3곳(또는 공개 도구 3종: Azimuth, DeepCRISPR, CRISPRon 등)을 비교표로 정리하세요. 입력·출력, on/off-target 처리 방식, 상업화 여부를 축으로 삼습니다.
3. **(기초 학습)** CRS(사이토카인 방출 증후군)의 등급 분류와 관리 원칙을 조사해, "AI가 CAR-T 독성을 예측한다면 어떤 임상 변수를 라벨로 써야 하는가"를 3~5줄로 제안하세요.
