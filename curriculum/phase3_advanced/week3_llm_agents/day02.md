# Day 2: 화학 Foundation Model — MolFormer, Uni-Mol, 사전학습 전략

> 이전 학습에서 범용 대형 언어 모델(LLM)이 텍스트를 사전학습해 지식노동을 자동화하는 원리를 다뤘습니다(Day 1). 오늘은 같은 "사전학습(pre-training) → 미세조정(fine-tuning)" 패러다임을 **분자 자체**에 적용한 **화학 Foundation Model**을 학습합니다. LLM이 자연어의 파운데이션 모델이라면, 오늘 다루는 모델들은 화학 공간의 파운데이션 모델입니다.

## 개요

**화학 Foundation Model(chemical foundation model)**은 라벨이 없는 수억 개의 분자를 자기지도학습(self-supervised learning)으로 사전학습하여, 분자의 범용 표현(representation)을 획득한 초거대 모델입니다. Phase 2에서 배운 QSAR·GNN 모델이 특정 물성 데이터셋 하나에 맞춰 처음부터 학습(from scratch)했다면, 파운데이션 모델은 **먼저 방대한 무라벨 분자로 화학의 "문법"을 익힌 뒤, 소량의 라벨 데이터로 특정 과제에 미세조정**합니다. 이 접근이 중요한 이유는 신약개발의 근본 제약인 **데이터 희소성** 때문입니다. 실험으로 얻은 활성·독성 라벨은 수백~수천 개에 불과한 경우가 많은데, 사전학습된 표현을 쓰면 적은 라벨로도 높은 성능을 얻을 수 있습니다. 약사-창업자에게 이 기술은 "우리 회사만의 소규모 실험 데이터로 경쟁력 있는 예측 모델을 만들 수 있는가"라는 질문에 직접 답합니다.

## 핵심 개념

### 1) 자기지도 사전학습 — 라벨 없이 배우는 법

파운데이션 모델의 핵심은 **자기지도 과제(pretext task)**입니다. 정답 라벨 대신 데이터 자체에서 학습 신호를 만듭니다. 대표적으로 **마스킹 언어 모델링(Masked Language Modeling, MLM)**이 있습니다 — SMILES 문자열의 일부 토큰을 가리고(masking) 이를 복원하도록 학습합니다. 이는 약학에서 익숙한 개념과 대응됩니다. 숙련된 약화학자가 분자 구조의 일부를 보고 나머지 작용기(functional group)를 추론하듯, 모델은 "이 위치에 올 수 있는 원자·결합"의 통계적 규칙을 수억 개 분자에서 학습합니다. 라벨(활성값)이 전혀 필요 없으므로 ChEMBL·ZINC·PubChem의 **수억 분자를 전부 학습 자원으로** 쓸 수 있다는 점이 핵심입니다.

### 2) 표현 방식에 따른 두 계보

화학 파운데이션 모델은 분자를 무엇으로 표현하느냐에 따라 갈립니다(Week 3 표현 방식 학습과 직접 연결).

| 계보 | 입력 표현 | 대표 모델 | 특징 |
|------|-----------|-----------|------|
| **1D 서열 기반** | SMILES 문자열 | ChemBERTa, MolFormer | 언어모델 그대로 차용, 대규모 학습 용이 |
| **2D 그래프 기반** | 분자 그래프 | GROVER, MPG | 원자·결합 구조 직접 보존 |
| **3D 구조 기반** | 원자 3D 좌표 | Uni-Mol, Uni-Mol2 | 입체 구조·결합 포즈까지 반영 |

**MolFormer**(IBM, 2022)는 SMILES를 언어로 취급해 **PubChem·ZINC의 약 11억 분자**로 사전학습한 트랜스포머로, 물성 예측에서 그래프 기반 모델에 필적하거나 능가하는 성능을 보고했습니다. 이는 "분자를 굳이 그래프로 안 다뤄도, 충분한 규모의 서열 학습이면 구조 정보가 암묵적으로 학습된다"는 것을 시사합니다.

### 3) 3D를 품은 파운데이션 모델 — Uni-Mol 계열

**Uni-Mol**(DeepModeling/DP Technology, 2023)은 원자의 **3차원 좌표**를 직접 입력받아 사전학습한 모델로, 결합 포즈·단백질 포켓 등 입체 정보가 중요한 과제에서 강점을 보입니다. 후속 **Uni-Mol2**(2024, NeurIPS 2024 채택)는 원자·그래프·기하 구조 특징을 함께 처리하는 **이중 트랙 트랜스포머(dual-track transformer)** 구조로, **약 8억 개 분자 컨포메이션(conformation)**을 사전학습하고 파라미터를 최대 **11억 개**까지 확장했습니다. 이는 화학 도메인에서도 LLM처럼 **스케일링(규모 확대)이 성능을 끌어올린다**는 경향을 실증한 사례입니다. 약학적으로 3D 표현이 중요한 이유는 명확합니다 — 거울상 이성질체(enantiomer)나 형태 이성질체처럼 2D 구조가 같아도 3D 배치가 다르면 약효·독성이 달라지며, 이는 1D/2D 표현이 놓치는 정보입니다.

### 4) 전이학습(transfer learning)이 데이터 희소성을 푸는 방식

사전학습된 표현을 새 과제로 옮기는 것을 **전이학습**이라 합니다. 방법은 두 가지입니다 — 사전학습 가중치를 **동결(freeze)**하고 위에 작은 예측 헤드만 학습하거나, 전체를 낮은 학습률로 **미세조정**합니다. 라벨이 극소수(수백 개)면 동결+헤드 방식이, 수천 개 이상이면 미세조정이 유리한 경향이 있습니다.

## 작동 원리와 아키텍처

바이브코딩으로 이 기술을 제품에 붙일 때 필요한 것은 사전학습을 직접 하는 능력이 아니라(수백만 달러의 계산 자원이 듭니다), **공개된 사전학습 모델을 가져와 우리 데이터로 미세조정하는 파이프라인**의 구조적 이해입니다.

```
[화학 파운데이션 모델 활용 파이프라인]
1. 사전학습 모델 로드: HuggingFace에서 MolFormer/ChemBERTa 가중치 다운로드
2. 입력 변환: 우리 분자(SMILES) → 토큰화 → 모델 입력 형식
3. 표현 추출: 사전학습 인코더 → 분자 임베딩(수백~수천 차원 벡터)
4. 과제 헤드: 임베딩 → FC layer → 우리 물성(예: 특정 표적 IC50) 예측
5. 미세조정: 우리 실험 라벨 수백~수천 개로 헤드(+인코더) 학습
```

핵심 설계 결정을 표로 정리합니다.

| 설계 결정 | 선택지 | 신약개발 맥락의 추천 | 이유 |
|-----------|--------|---------------------|------|
| 표현 계보 | 1D / 2D / 3D | 입체 중요하면 3D(Uni-Mol) | 이성질체·포즈 구분 필요 시 |
| 전이 방식 | 동결 / 미세조정 | 라벨 <수백이면 동결 | 과적합(overfitting) 방지 |
| 도메인 적합 | 범용 / 자체 재학습 | 자사 화학공간 좁으면 추가 사전학습 | 분포 이동(distribution shift) 완화 |

> 핵심: 파운데이션 모델의 임베딩은 **재사용 가능한 자산**입니다. 한 번 추출한 분자 표현을 물성 예측·유사도 검색·클러스터링 등 여러 다운스트림 과제에 공유할 수 있어, 개별 모델을 처음부터 만드는 것보다 개발 비용이 낮습니다.

## 신약개발 적용

화학 파운데이션 모델은 이미 실무 성능을 입증하고 있습니다.

- **저데이터 물성 예측**: MolFormer는 MoleculeNet(Day: Phase 1 Week 4에서 다룬 벤치마크)의 다수 과제에서 라벨이 적은 상황에서도 강건한 성능을 보고했습니다. 실험 라벨이 수백 개뿐인 신생 바이오텍에 특히 유리합니다.
- **3D 과제에서의 우위**: Uni-Mol 계열은 결합 포즈 예측·단백질-리간드 상호작용 등 3D 정보가 결정적인 과제에서 강점을 보이며, 후속 **Uni-Mol3(2025)**는 유기 반응(organic reaction) 모델링으로 범위를 확장했습니다(서지 확인 필요).
- **기존 방식 대비 개선**을 비교하면 다음과 같습니다.

| 항목 | 처음부터 학습(from scratch) | 파운데이션 모델 미세조정 |
|------|------------------------------|--------------------------|
| 필요 라벨 수 | 수천~수만 개 | 수백~수천 개 |
| 저데이터 성능 | 과적합 위험 큼 | 사전학습 지식으로 보완 |
| 개발 시간 | 과제마다 새로 설계 | 공통 표현 재사용 |
| 계산 비용 | 매번 전체 학습 | 미세조정만(경량) |

> 유의: 파운데이션 모델의 예측도 **후보·초안**이며, 특히 사전학습 데이터의 화학 공간을 벗어난 신규 골격(novel scaffold)에서는 신뢰도가 떨어질 수 있습니다. 예측된 분자 속성을 확실성으로 받아들여선 안 되며, 불확실성 추정과 실험 검증이 필요합니다.

## 창업 관점

Phase 3(트렌드) 단계인 만큼 시장과 진입 전략을 구체적으로 봅니다. 화학 파운데이션 모델은 "누구나 공개 가중치를 쓸 수 있다"는 점에서 범용 LLM과 같은 딜레마를 안고 있습니다 — 모델 자체는 해자가 되기 어렵습니다.

- **제품 아이디어**: (1) 소규모 바이오텍을 위한 **"저데이터 물성 예측 SaaS"** — 고객이 자사 실험 데이터 수백 건을 올리면 사전학습 모델을 미세조정해 맞춤 예측기를 제공, (2) 특정 표적군(예: kinase, GPCR)에 **추가 사전학습(domain-adaptive pre-training)**한 특화 모델, (3) 여러 파운데이션 모델의 임베딩을 앙상블해 불확실성까지 제공하는 스크리닝 도구.
- **시장·경쟁 구도**: 파운데이션 모델 원천 기술은 IBM(MolFormer), DeepModeling/DP Technology(Uni-Mol) 등 대형 조직·오픈소스가 주도합니다. **Schrödinger, Iktos, Chemify** 등이 응용 계층에 있습니다. 빈 공간은 **"고객의 좁은 화학 공간에 맞춘 미세조정 + 약학적 해석 + 불확실성 정량화"**가 결합된 수직 도구입니다.
- **기술적 해자(moat)**: 공개 모델 접근성은 해자가 아닙니다. 해자는 ① 특정 표적·질환의 **독점 실험 데이터**(미세조정 품질을 좌우), ② 어떤 예측이 임상적으로 유의미한지 판단하는 **약학적 임계값 설정 능력**(Day 1 ADMET 판단력과 연결), ③ 고객 피드백으로 개선되는 검증 루프입니다. 특히 ②는 순수 ML 팀이 흉내내기 가장 어려운 지점입니다.
- **MVP 구상**: 바이브코딩으로 HuggingFace의 공개 MolFormer/ChemBERTa를 불러와 공개 ChEMBL 데이터로 단일 표적 활성 예측기를 만들고, 소형 바이오텍에 "당신의 데이터로 성능이 얼마나 오르는가"를 무료 파일럿으로 보여주는 것이 현실적 시작점입니다. 미세조정 전후 성능 향상 폭 자체가 강력한 세일즈 근거가 됩니다.

## 오늘의 과제

1. **(기초 학습)** 자기지도 사전학습(마스킹)과 지도학습 미세조정의 차이를 각각 3줄로 정리하고, "실험 라벨이 300개뿐인 신규 표적 활성 예측" 상황에서 동결(freeze)과 미세조정 중 무엇을 택할지와 그 이유를 1문단으로 쓰세요.
2. **(비즈니스 분석)** 화학 파운데이션 모델을 활용·제공하는 회사·프로젝트 3곳(예: IBM MolFormer, DP Technology Uni-Mol, Schrödinger)을 비교표로 정리하세요. 축: 표현 계보(1D/2D/3D), 공개 여부, 대상 사용자, 수익 모델. 약사-창업자가 진입할 빈 공간을 한 문단으로 결론지으세요.
3. **(리서치 정리)** "3D 표현(Uni-Mol)이 1D/2D 대비 신약개발에서 언제 결정적인가"를 주제로 1페이지를 작성하세요. 거울상 이성질체·결합 포즈·입체 선택성 중 하나의 구체적 약학 사례를 들어, 3D 정보가 없으면 놓치는 예측 실패를 서술합니다.
