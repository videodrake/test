# Day 71: AI 신약개발 제품의 유형과 설계 패턴

> 지난주(Day 66~70)는 데이터·오픈소스·MLOps·배포를 하나의 기술 스택으로 엮어 "굴러가는 인프라"를 갖추는 법을 다뤘습니다. 오늘부터 시작하는 이번 주(Week 3)는 그 인프라 위에 올릴 **제품 자체의 설계**로 초점을 옮깁니다. 첫날인 오늘은 AI 신약개발 제품이 어떤 유형으로 나뉘는지, 그리고 각 유형이 공통적으로 따르는 설계 패턴(design pattern)은 무엇인지 지도를 그립니다.

## 개요

AI 신약개발 **제품**은 모델(model)과 다릅니다. 모델은 입력을 받아 예측을 내놓는 함수이고, 제품은 그 예측을 **사람이 실제로 의사결정에 쓰도록** 감싼 시스템입니다. 같은 hERG 독성 예측 모델이라도 과학자가 매일 여는 웹 워크벤치로 포장하느냐, 제약사 파이프라인에 꽂히는 API로 포장하느냐, 아니면 직접 신약 후보를 만들어 라이선스아웃하는 파이프라인 회사의 내부 엔진으로 쓰느냐에 따라 전혀 다른 사업이 됩니다. 오늘의 목표는 제품 유형의 분류 체계(taxonomy)와, 유형을 가로지르는 공통 설계 패턴을 익혀, 창업자로서 "나는 무엇을 만들 것인가"를 구조적으로 결정할 수 있게 하는 것입니다.

## 핵심 개념

AI 신약개발 제품은 크게 세 가지 **비즈니스 유형**으로 나뉩니다. 이는 곧 수익 구조와 조직 형태를 결정합니다.

| 유형 | 파는 것 | 고객 | 수익 구조 |
|------|---------|------|----------|
| **도구/SaaS형** | 소프트웨어 사용권 | 제약사·바이오텍 연구자 | 구독·라이선스(ACV) |
| **플랫폼형** | 통합 워크플로우·데이터 환경 | R&D 조직 전체 | 플랫폼 구독 + 사용량 |
| **파이프라인/TechBio형** | 신약 후보 자산 자체 | 제약사(라이선스아웃) | 선급금 + 마일스톤 + 로열티 |

세 유형을 가르는 핵심 질문은 **"누가 위험을 지는가"**입니다. 도구형은 고객이 신약개발 위험을 지고 우리는 도구만 팝니다(저위험·저보상). 파이프라인형은 우리가 직접 후보를 발굴해 임상 위험까지 감수합니다(고위험·고보상). 약학 전공자에게 이 선택은 익숙한 사고입니다 — 이는 **용량-반응 곡선의 위험·효용 균형(risk-benefit)**과 구조가 같습니다. 어느 지점에서 활동할지는 가진 자본과 인내심(활주 거리, runway)에 달려 있습니다.

제품 유형을 관통하는 개념이 **설계 패턴**입니다. 설계 패턴이란 반복되는 설계 문제에 대한 검증된 해법 틀로, 바이브코딩으로 제품을 지시할 때 "어떤 구조로 만들라"의 어휘가 됩니다.

## 작동 원리와 아키텍처

AI 신약개발 제품에서 반복적으로 등장하는 네 가지 핵심 설계 패턴을 입력→처리→출력 흐름으로 정리합니다.

```
핵심 설계 패턴 4종:
1. 인간 개입 루프(Human-in-the-loop): 예측 → 과학자 검토·수정 → 재예측
   용도: 리드 최적화처럼 전문가 판단이 필수인 영역
2. 배치 스크리닝(Batch): 수백만 분자 업로드 → 대량 추론 → 랭킹 반환
   용도: 가상 스크리닝, 라이브러리 필터링
3. 대화형 워크벤치(Interactive): 분자 그리기 → 즉시 물성 표시 → 반복
   용도: 의약화학자의 일상적 설계(SAR 탐색)
4. API/임베디드: 외부 파이프라인이 /predict 호출 → 결과 JSON 반환
   용도: 고객사 기존 워크플로우에 삽입
```

대부분의 성공한 제품은 이 패턴들을 **조합**합니다. 예를 들어 워크벤치(패턴 3) 안에 배치 스크리닝(패턴 2)을 메뉴로 넣고, 전체를 API(패턴 4)로도 노출하는 식입니다. 패턴 선택이 곧 아키텍처 결정으로 이어지므로, 아래 표로 설계 결정을 정리합니다.

| 설계 결정 | 선택지 | 추천(초기) | 이유 |
|-----------|--------|-----------|------|
| 상호작용 방식 | 배치 / 대화형 | 대화형 워크벤치 | 과학자 일상에 붙어 이탈률↓ |
| 예측 신뢰 표시 | 점수만 / 불확실성 동반 | 불확실성 동반 | 규제·신뢰 확보(Day 68 재현성) |
| 통합 방식 | 독립앱 / API 우선 | API 우선 설계 | 나중에 임베디드로 확장 용이 |
| 결과 설명 | 블랙박스 / 설명 가능 | 설명 가능(XAI) | 약학적 판단·감사 대응 |

> 설계 원칙: **예측값만 던지지 말고, "이 예측을 얼마나 믿어도 되는가"를 함께 설계하라.** 약학 전공자는 임상적으로 유의미한 임계값(threshold)과 허용 가능한 불확실성 범위를 알기에, 이 설계 결정을 비약학 개발자보다 정확히 내릴 수 있습니다.

## 신약개발 적용

세 유형이 실제 기업에서 어떻게 구현되는지 구체적 사례로 봅니다.

- **도구/SaaS형 — Schrödinger LiveDesign**: 물리 기반 시뮬레이션(FEP+, Glide, Maestro)에 ML을 얹어 의약화학자용 설계 환경을 판매합니다. 2024년 소프트웨어 매출 약 1억 8천만 달러(전년 대비 13% 성장), 연 계약금액(ACV) 50만 달러 이상 계약의 100% 유지율을 보고했습니다. 도구형의 전형적 지표인 "높은 유지율 + 계약 규모 확대"가 드러납니다.
- **플랫폼형 — Insilico Medicine의 Pharma.AI**: 타겟 발굴(PandaOmics)부터 분자 생성(Chemistry42)까지 단계를 통합한 엔드투엔드 플랫폼으로, 자체 후보 발굴과 외부 제공을 겸합니다. 통합 환경은 단일 모델보다 고객 교체 비용(switching cost)을 높여 해자로 작용합니다.
- **파이프라인/TechBio형 — Recursion**: 자체 플랫폼으로 후보를 발굴해 임상까지 끌고 가는 구조입니다. 동시에 Schrödinger는 2024년 Novartis와 선급금 1억 5천만 달러 + 최대 약 23억 달러 규모 마일스톤의 협업을 발표해, 도구형 기업도 파이프라인형 수익(마일스톤·로열티)을 혼합할 수 있음을 보여줬습니다.

| 유형 | 초기 자본 요구 | 매출 발생 속도 | 상방(upside) |
|------|--------------|--------------|-------------|
| 도구/SaaS | 낮음 | 빠름(구독) | 중간 |
| 플랫폼 | 중간 | 중간 | 큼 |
| 파이프라인 | 매우 큼 | 느림(마일스톤) | 매우 큼 |

## 창업 관점

Phase 4 후반답게 오늘 내용의 절반은 창업 의사결정입니다.

- **약학 전공자의 진입점은 "설명 가능한 도구형"**: 자본이 제한된 초기 창업자가 파이프라인형(임상 위험 + 수억 달러 자본)으로 시작하기는 어렵습니다. 현실적 진입점은 **특정 약학 난제에 특화된 도구/SaaS**입니다 — 예컨대 DDI(약물 상호작용) 예측, hERG 안전성, 또는 규제 제출용 ADMET 리포트 생성처럼, 약학 지식이 곧 제품 차별화가 되는 좁은 영역입니다.
- **해자는 모델이 아니라 "워크플로우 장악 + 데이터 피드백 루프"**: 모델 자체는 오픈소스로 평준화됩니다(Day 67). 진짜 해자는 (1) 과학자의 일상 워크플로우에 깊이 박혀 교체 비용을 높이고, (2) 사용자가 쓸수록 데이터가 쌓여 모델이 좋아지는 피드백 루프를 만드는 것입니다. 인간 개입 루프(패턴 1)는 그 자체가 라벨링된 데이터를 생성하는 장치이기도 합니다.
- **MVP 구상**: 지난주 만든 최소 스택 위에, 단일 물성(예: hERG) 예측을 **대화형 워크벤치 + 불확실성 표시 + API**로 노출하는 제품을 바이브코딩으로 구성해보세요. 핵심은 예측 점수에 더해 "임상적으로 이 값이 무엇을 의미하는가"라는 약학적 해석 레이어를 붙이는 것입니다. 이 해석 레이어가 비약학 경쟁자가 복제하기 가장 어려운 부분입니다.

## 오늘의 과제

1. **(비즈니스 분석)** 도구/SaaS·플랫폼·파이프라인 세 유형 중 여러분이 창업할 유형을 하나 고르고, 그 선택의 근거를 "자본 요구·매출 속도·약학 강점 활용도" 세 축으로 한 페이지에 정리하세요. 왜 나머지 둘은 지금 선택하지 않는지도 한 문단씩 쓰세요. 40분.
2. **(기초 학습)** 본문의 설계 패턴 4종 중 여러분 MVP에 쓸 패턴 2개를 조합하고, 그 조합의 입력→처리→출력 흐름을 의사코드 10줄 이내로 스케치하세요. 각 단계에서 "약학 지식이 개입하는 지점"을 최소 1곳 표시하세요. 30분.
3. **(리서치 정리)** Schrödinger·Insilico·Recursion 중 한 곳을 골라, 그 회사가 세 유형 중 어디에 속하며 최근(2024~2025) 어떤 제품·계약으로 수익을 내는지 반 페이지로 정리하세요. 수치(매출·계약 규모)를 최소 1개 포함하세요. 30분.
